  1. 00:17

    Fox technical check-in, before the agenda

    Elliott: Fox is looking very solid. Native 90 fps is close but would take a lot more work, so the plan is probably 60 fps reprojected. Todd has been working through the motion-sickness items on the FQA list. Some smooth-turning cameras are fixed, but the livery editor still has one.

    Elliott still wants a comfort mode that locks pitch and keeps the camera smoothly behind the car, because moves like the camera turning after a crash break standard VR comfort rules. The UI update is mostly done: It's amazing how much the UI UX of the game relates to how much this feels like a VR native. One release candidate went out this morning, and another is coming.
